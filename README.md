# ts04-django-react-auth

Reference project for [gherkin-ai](https://github.com/FennerEduardo/gherkin-ai-cli) 3.0.0. JWT-authenticated transactions in Django with Django REST framework, and a React 19 frontend.

Everything in `generated-specs/` was generated by `ghk generate` from the specification in `features/django_drf_transaction.feature`. The project builds, and its generated tests and runtime integration suite pass, as verified on 2026-10-06 (see [Verification](#verification)).

## Stack

| Part | Technology |
|---|---|
| Backend | Django + Django REST framework (Python 3.12) |
| Frontend | React 19 (Redux Toolkit, Vite) |
| Runtime kernel | PostgreSQL command service with idempotency and transactional outbox, RabbitMQ relay and inbox consumer with dead-letter queue, saga orchestrator, OpenTelemetry trace propagation |

## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them in `generated-specs` with the toolchain installed, or inside the official image `python:3.12-slim`.

```bash
cd generated-specs
pip install -q -e ".[test]"
python -m compileall -q app config
python manage.py check
pytest -q -rs -m "not integration"
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
pytest -q -rs -m integration
```

Frontend (`generated-specs/frontend`, image `node:24-bookworm`):

```bash
cd generated-specs/frontend
npm install --no-audit --no-fund --loglevel=error
npm run build
npm test
```
